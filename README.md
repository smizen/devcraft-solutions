## 🌐 Déploiement Gratuit sur GitHub Pages

```bash
git init
git add .
git commit -m "feat: DevCraft Solutions showcase"
git branch -M main
git remote add origin https://github.com/<VOTRE-PSEUDO>/devcraft-solutions.git
git push -u origin main
```

Activez GitHub Pages dans **Settings > Pages > Branch: `main` / `(root)` > Save**.
